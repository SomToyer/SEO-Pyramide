## 🔄 Dynamisches Mapping (optional)

### Kontext-basierte Auswahl:

Wenn möglich, sollte die Produkt-Box dynamisch basierend auf dem Content ausgewählt werden:

**Beispiel-Logik:**
```javascript
function selectProduct(context) {
  // Story-Seiten: Produkt zur Story
  if (context.type === 'story' && context.productSlug) {
    return context.productSlug; // z.B. 'herbert-hahn'
  }

  // Kategorie LRS: Krümelbrandt
  if (context.category === 'lrs') {
    return 'kruemelbrandt';
  }

  // Kategorie Gutenachtgeschichten: Luna
  if (context.category === 'gutenachtgeschichten') {
    return 'luna';
  }

  // Default: Pionierset
  return 'pionierset';
}
```

## 📊 Produkt-Box Varianten

### Standard-Box (inline)
- **Größe**: Medium (ca. 300-400px breit)
- **Position**: Im Content-Flow
- **Produkt**: Spezifisch zum Inhalt

### CTA-Banner (full-width)
- **Größe**: Full-width (100%)
- **Position**: Am Ende des Artikels
- **Produkt**: Meist Pionierset (Haupt-CTA)
- **Design**: Prominent, mit Hintergrund, groß

### Sidebar-Box (klein)
- **Größe**: Klein (ca. 250px breit)
- **Position**: Rechte Sidebar (optional)
- **Produkt**: Rotierend oder passend zum Inhalt

## 🔗 Tracking & Analytics (optional)

### UTM-Parameter für Produkt-Links:
```
https://fluxie.de/produkt/pionierset/?utm_source=blog&utm_medium=product_box&utm_campaign=silbentrennung
```

**Parameter:**
- `utm_source`: `blog` oder `lesewelt`
- `utm_medium`: `product_box_top`, `product_box_mid`, `cta_banner`
- `utm_campaign`: Artikel-Slug oder Kategorie

**Nutzen**: Tracking, welche Produkt-Boxen am besten konvertieren
